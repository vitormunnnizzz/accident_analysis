## Descrição

Este projeto tem como objetivo realizar uma **Análise Exploratória de Dados (EDA)** e aplicar processos de **ETL (Extract, Transform, Load)** em uma base de dados de acidentes de trânsito. A análise busca identificar padrões, tendências e possíveis fatores associados à ocorrência de acidentes, além de apresentar visualizações que auxiliem na compreensão dos dados.

O projeto também inclui a padronização e tratamento de variáveis importantes, como informações geográficas e horários dos acidentes, permitindo uma análise mais confiável e estruturada.

## Estrutura do Projeto

O projeto inclui diferentes etapas de tratamento e análise dos dados:

- **Base de Dados de Acidentes**: Conjunto de dados contendo registros de acidentes de trânsito.
- **Tratamento de Termos Geográficos**: Padronização de nomes de locais e regiões para evitar inconsistências.
- **Ajuste de Horários**: Limpeza e formatação da coluna de horário para análise temporal.
- **Tratamento da Coluna Consórcio**: Organização e correção de valores inconsistentes.
- **Análise Exploratória de Dados (EDA)**: Identificação de padrões e distribuição dos acidentes.
- **Mapas de Colisão**: Visualização geográfica dos acidentes para identificar regiões com maior incidência.

Essas análises ajudam a compreender melhor o comportamento dos acidentes e possíveis fatores associados à sua ocorrência.

## Modelagem dos Dados

- **Limpeza e Organização**: Os dados foram tratados para remover inconsistências e padronizar informações.
- **Transformações (ETL)**: Aplicação de processos de transformação para adequar os dados à análise.
- **Preparação para Análise**: Estruturação dos dados para facilitar visualizações e análises exploratórias no notebook.

## Tecnologias Utilizadas

- **Python**: Linguagem principal utilizada para análise e tratamento dos dados.
- **Pandas**: Manipulação e transformação dos dados.
- **NumPy**: Operações numéricas e apoio à análise de dados.
- **Matplotlib**: Criação de visualizações e gráficos.
- **Jupyter Notebook**: Ambiente utilizado para desenvolvimento da análise.

## Resultados Esperados

A análise deste projeto permite:

- **Identificação de Padrões de Acidentes**: Entendimento de como e quando os acidentes ocorrem com maior frequência.
- **Análise Geográfica**: Visualização de regiões com maior incidência de colisões.
- **Melhoria na Qualidade dos Dados**: Dados tratados e padronizados para futuras análises.
- **Base para Projetos Futuros**: Possibilidade de aplicação de modelos de Machine Learning para previsão de acidentes.
